# 极简现代风格 CSS 重构计划

## 任务概述
将当前博客的 CSS 从"文人风骨"风格重构为"极简现代"风格。用户反馈当前 CSS "太丑"，需要重新设计。

## 当前状态分析
- 文件位置：`d:\myblog\assets\css\extended\custom.css`
- 当前风格：宋体标题 + 黑体正文 + 极客蓝（#3b82f6）
- 问题：用户觉得不好看，需要彻底重做

## 极简现代风格定义
参考 Zach Leatherman、Notion、Apple 等设计：
- **大量留白** - 呼吸感强
- **无衬线字体** - 干净现代
- **克制的颜色** - 黑白灰为主，少量强调色
- **精致的排版** - 字号层级清晰
- **微妙的交互** - 平滑过渡，不突兀

## 具体修改方案

### 1. 颜色系统
```css
:root {
  --text-primary: #1a1a1a;      /* 近黑， softer than pure black */
  --text-secondary: #666;        /* 中灰 */
  --text-muted: #999;            /* 浅灰 */
  --bg-primary: #fff;            /* 纯白 */
  --bg-secondary: #f5f5f5;       /* 微灰背景 */
  --accent: #0066cc;             /* 克制的蓝色 */
  --border: #e5e5e5;             /* 极浅边框 */
}
```

### 2. 字体系统
- 标题：系统无衬线字体栈（-apple-system, BlinkMacSystemFont, "Segoe UI"）
- 正文：同上，保持统一
- 代码：等宽字体
- **取消宋体**，统一使用现代无衬线字体

### 3. 排版尺度
- 文章标题：2rem（32px）- 克制的大
- 正文：1rem（16px）- 标准阅读尺寸
- 行高：1.6-1.8 - 舒适阅读
- 段落间距：1.5em - 充足留白

### 4. 布局优化
- 最大内容宽度：680px - 适合阅读
- 居中布局
- 减少边框和阴影，用留白分隔

### 5. 交互细节
- 链接：下划线 hover 效果
- 按钮：圆角 6px，微妙阴影
- 过渡：0.2s ease

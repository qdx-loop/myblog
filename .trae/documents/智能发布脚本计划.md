# 智能发布脚本计划（简化版）

## 任务概述
创建一个 Hugo 博客自动发布脚本，支持选择发布范围、冲突处理、协议自动切换和错误捕获。

## 功能需求

1. **发布范围选择**（运行时选择）
   - 选项1：发布全部内容
   - 选项2：仅发布 content/posts/ 目录

2. **冲突处理**
   - 检测本地和远程差异
   - 提供选项：强制推送（覆盖远程）/ 拉取合并 / 取消

3. **协议自动切换**
   - 优先尝试 HTTPS
   - 失败自动切换 SSH

4. **错误处理**
   - 捕获所有错误输出
   - 自动复制到剪贴板

## 实现

### 新建文件
`d:\myblog\deploy.bat` - 单个完整脚本

### 使用方式
双击运行，根据提示选择即可
